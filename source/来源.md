# 实现依据

- Waveshare M3 SDK 与原生协议字段：https://github.com/waveshareteam/waveshare_roarm_sdk/blob/main/roarm_sdk/common.py
- Waveshare M3 关节与行程：https://docs.waveshare.net/RoArm-M3/Introduction/
- Orbbec SDK Python：https://github.com/orbbec/pyorbbecsdk
- D2C 接口示例：https://github.com/orbbec/pyorbbecsdk/blob/v2-main/examples/beginner/03_color_and_depth_aligned.py

本软件独立实现串口及界面，未修改机械臂或相机固件。Orbbec 使用已安装的官方二进制 SDK。
