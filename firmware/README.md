## 固件用途

本目录保存 RoArm-M3-Pro 的示教固件源码。应用保留上电回中路径，增加 T626 七舵机角度和 T211 手动示教接口。正常运行中，T211 cmd=0 直接关闭舵机扭矩，不移动到预设位置。外部 12V 电源仍接通。cmd=1 在读取并核对七个舵机的当前位置目标后恢复保持。cmd=2 只查询。桌面端只在确认协议和七项回读后显示成功。释放前请先托稳负载。

Release 中的 Teach-app.bin 是 ESP32 应用镜像。写入位置取决于本机分区表和当前启动槽。升级前备份原应用，核对主控型号、分区容量和启动槽，不要按其他板子的地址直接覆盖。


## 装好后通过 USB 更新，无需 BOOT

让机械臂停稳并有支撑，关闭占用串口的软件。使用安装了 pyserial 的 Python 运行：

```powershell
python tools/update_firmware.py firmware/RoarmStudio-1.0-Teach-app.bin --port COM18
```

把端口换成本机实际端口。第一次从缺少串口更新接口的固件升级仍需要下载模式。此后工具向 T625 查询能力，通过 T620–T624 把应用写入另一启动槽，检查传输大小和 SHA-256，通过镜像校验后切换启动槽并重启。普通升级不写入分区表、引导程序或舵机 EEPROM。重启会执行原固件的上电回中流程。请一直保持 USB 和 12V 供电，等工具完成。

与先前双肩反馈版本相比，本次保留原来的 T626 角度字段、运动学、回中流程及启动 PID 设置。升级仅在维护期间阻止运动；网页以 gzip 存储以便镜像放入原应用槽。
