# RoarmStudio 1.2 · Windows x64

- **工业视觉工作台**　黑灰界面采用单行标题栏。顶部标签只切换左上控制区，关节控制、示教和设备设置打开后，姿态、双相机和诊断仍可见。轮盘随窗口放大，实时 XYZ 数值和精确输入框更大。
- **姿态与相机**　使用 Waveshare RoArm-M3 的分关节模型，随关节反馈更新。工作区网格在底座后方截断，滚轮缩放，左键拖动旋转，右键拖动平移。右下显示手部相机和彩色深度融合画面。
- **状态与诊断**　顶部显示机械臂串口、相机连接、反馈间隔及扭矩状态。左下可切换日志、关节角度和温度。固件未提供的温度显示为缺值，回放启用带载容差后由「严格执行」切换为「降标执行」。
- **前方 210° 软件限位**　以底座零位为正前方，点动、精确坐标、关节指令和回放限制在左右各 105° 内。含后方点位的旧轨迹会被拒绝。红色「急停」取消待发动作和回放，已发送的目标可能继续执行。

`Setup-x64.exe` 为安装包，`Windows-x64.zip` 完整解压后运行 `RoarmStudio.exe`。`SHA256SUMS.txt` 用于校验下载文件。可选示教固件见 [v1.0 发布页](https://github.com/Azucia/RoArmStudio/releases/tag/v1.0)。

本版通过离线回归测试和 Windows 安装启动检查。实机联调待验证。
