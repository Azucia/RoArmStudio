# RoarmStudio 1.1 · Windows x64

v1.1 修复带载取消动作、反馈中断和示教回放中的四个问题。

- 取消后续动作或回放异常结束时，保留最后发送的关节目标。已发送的目标可能继续执行。
- 回放超过 0.6 秒未收到反馈，或收到关节扭矩关闭的反馈时，取消后续动作。反馈恢复后需要手动重新开始回放。
- 回放等待本机完整写出串口指令，再检查关节到位反馈。未写出或写入不完整的指令会终止本次回放。
- 提交运动和实际发送前，均检查关节扭矩关闭状态。

`Setup-x64.exe` 是安装包，`Windows-x64.zip` 解压后可直接运行 `RoarmStudio.exe`，`SHA256SUMS.txt` 用于校验下载文件。可选的示教固件仍可从 [v1.0 发布页](https://github.com/Azucia/RoArmStudio/releases/tag/v1.0) 下载。

本版通过了模拟串口回归测试和 Windows 安装启动检查。带载运动仍待实机验证。
