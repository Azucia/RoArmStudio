# RoarmStudio 2.4 · Windows x64

- 示教页提供「示教1」至「示教12」共 12 个槽位。录制结束后自动保存，选中槽位可查看时长和关键点数，也可导入旧轨迹。
- Python SDK 2.4.0 支持查询槽位、按名称回放并等待结果。本机 HTTP API 提供同样的入口。
- 机械臂预览随示教回放更新红色目标箭头及 XYZ 数值。
- 末端位置偏差超过 10 mm 时显示「降标执行」。示教到位反馈也用于判定 SDK 的回放结果。

下载 Windows 安装包，或解压便携版后运行 `RoarmStudio.exe`。首页提供可复制的 Python SDK 与 HTTP API 示例。[查看接入说明](https://github.com/Azucia/RoArmStudio#v20-本机-api-与-python-sdk)

本版通过离线测试和 Windows 启动检查。实机带载跟随效果待验证。
