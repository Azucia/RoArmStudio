# RoarmStudio 2.5.4 · Windows x64

- 示教停顿点确认停稳后，若只有小幅肩肘误差导致末端超差，按实际反馈补偿肩肘，偏置每轴最多 2.5°，最多尝试两次。
- 只有第一步改善误差才允许再次补偿。夹爪保持最后已发目标，末端仍须在 10 mm 内且停稳后才继续。
- 微调后的偏置在离开停顿点后逐渐衰减。沿用 2.5.3 的固件。
- 相对 v2.4，设备页新增全局舵机限速；普通中间点按统一轨迹时钟发送，跟随超差时限时等待追上，反馈过期时停止。
- 示教记录时轻微越过腕部 ±90° 的采样会标记贴边修正；回放不会因夹爪闭合不到目标角度而停下，收紧动作会在 180° 范围内增加 10° 的预紧目标。

桌面版可直接使用现有兼容固件。仓库另含夹爪 3 A 保护的可选固件源码，桌面安装不会刷写 ESP32。
